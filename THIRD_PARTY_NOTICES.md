# Third-party components

DownTrack launches local media tools as background child processes. Media processing never opens a visible terminal window.

## yt-dlp
Official project and release binaries:
https://github.com/yt-dlp/yt-dlp

## FFmpeg
FFmpeg Windows Essentials binaries are downloaded from gyan.dev:
https://www.gyan.dev/ffmpeg/builds/

The FFmpeg project lists gyan.dev among its Windows binary providers:
https://www.ffmpeg.org/download.html
